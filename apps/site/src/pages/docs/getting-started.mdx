# Getting started

## Install

### Install script

macOS and Linux, no sudo:

```sh
curl -fsSL https://raw.githubusercontent.com/flexdinesh/servef/main/scripts/install.sh | sh
```

It installs the latest release's `servef` in `~/.local/bin` (or `~/bin` when
that is on your `PATH`), and prints the line to add when the directory is not
on `PATH`. Run it again to update.

The install scripts are the supported way to install servef; Homebrew and
`go install` are no longer offered. A specific version's archive is on
[GitHub Releases](https://github.com/flexdinesh/servef/releases): put its
`servef` binary in `~/.local/bin`.

### Desktop app

Optional. The desktop app and the CLI, macOS and Linux:

```sh
curl -fsSL https://raw.githubusercontent.com/flexdinesh/servef/main/scripts/install-desktop.sh | sh
```

Packages are also on
[GitHub Releases](https://github.com/flexdinesh/servef/releases); see
[Desktop app](/docs/desktop).

### Uninstall

```sh
curl -fsSL https://raw.githubusercontent.com/flexdinesh/servef/main/scripts/uninstall.sh | sh
```

It removes the CLI and the desktop app however they were installed in your
home directory, prints the command for the deb or a copy that Homebrew,
mise, or another tool installed earlier, and keeps your data.

## Run

Serve the current directory:

```sh
servef .
```

With the [desktop app](/docs/desktop) installed, servef opens the directory in it.
Otherwise it opens the browser UI on the first free port from `7971` through
`7980`; `servef browser .` always does. See [Usage](/docs/usage) for directories,
scope, and ports, and
[Browsing](/docs/browsing) for the UI.

See all options:

```sh
servef --help
```
