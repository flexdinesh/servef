# Getting started

## Install

### Install script

macOS and Linux, no sudo. This installs the CLI and the
[desktop app](/docs/desktop):

```sh
curl -fsSL https://raw.githubusercontent.com/flexdinesh/srcz/main/scripts/install.sh | sh
```

For the CLI alone, such as on a server:

```sh
curl -fsSL https://raw.githubusercontent.com/flexdinesh/srcz/main/scripts/install.sh | sh -s -- --cli-only
```

It puts the latest release's `srcz` in `~/.local/bin` (or `~/bin` when that is
on your `PATH`), and prints the line to add when the directory is not on `PATH`.
The desktop app needs WebKitGTK 4.1 on Linux. Run the script again to update,
after quitting the app; it stops while the app runs.

The install scripts are the supported way to install Source Zero; Homebrew and
`go install` are no longer offered. A specific version's archive is on
[GitHub Releases](https://github.com/flexdinesh/srcz/releases): put its
`srcz` binary in `~/.local/bin`.

### Uninstall

```sh
curl -fsSL https://raw.githubusercontent.com/flexdinesh/srcz/main/scripts/uninstall.sh | sh
```

It removes the CLI and the desktop app however they were installed in your
home directory, prints the command for a copy that Homebrew, mise, apt, or
another tool installed earlier, and keeps your data.

## Run

Serve the current directory:

```sh
srcz .
```

With the [desktop app](/docs/desktop) installed, Source Zero opens the directory in it.
Otherwise it opens the browser UI on the first free port from `7971` through
`7980`; `srcz browser .` always does. See [Usage](/docs/usage) for directories,
scope, and ports, and
[Browsing](/docs/browsing) for the UI.

See all options:

```sh
srcz --help
```
