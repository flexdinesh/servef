# Native app (experimental)

`servef-native` is an experiment: servef drawn with native widgets instead of
a web view. It browses the same projects through the same servef daemon or
servers, with a smaller feature set than the [desktop app](/docs/desktop),
which stays the recommended app. Expect rough edges; things may change or go
away.

What it does today:

- Opens projects on this computer (through the servef daemon) or on a servef
  server started with `servef browser`, on this machine or another.
- Browses the file tree, shows highlighted source with line numbers, find,
  and copy, and previews Markdown with its links, images, highlighted code
  blocks, and Mermaid diagrams (also `.mmd` files). Highlighting and diagrams
  come from the same engines the browser uses; a diagram with a syntax error
  shows its source and the error. Diagrams expand into a dialog with zoom and
  drag pan. Files with a formatter have a read-only **Format** view.
- Shows images with fit and zoom (not yet `.ico` or `.avif`, which say they
  can't display), and says so for binary, too-large, and large files.
- Selects lines from the gutter (click, Shift-click, drag) and copies the
  file path, a line reference like `src/main.go:5-9`, or a link to the lines.
  Back and forward return to each document where you left it.
- Opens files in tabs: switch with a click or the arrow keys, close with the
  close button, Delete, or the tab's menu (Close, Close Others, Close to the
  Right, Close All). The activity bar switches between Explorer and Source
  Control (Ctrl+Shift+E, Ctrl+Shift+G; ⇧⌘E, ⇧⌘G on macOS); clicking the shown
  view or Ctrl+B (⌘B) hides the sidebar, and its edge drags to resize it.
- Remembers each project's tabs, active tab, and open folders, the last
  project, and the sidebar, and restores them on the next start.
- Reviews uncommitted changes: **Source Control** in the sidebar lists the
  working tree's changes since the last commit; choosing one shows its diff side by
  side or unified, as hunks or the full file, optionally ignoring leading and
  trailing whitespace, in one **Uncommitted** tab. Binary and large files say
  so instead.
- Follows live updates: the open file, the change list, and the open diff
  reread when the project changes on disk.

Not yet: commit history, branch and range compares, search, code navigation,
walkthroughs, and the Welcome tab. Use the desktop app or the browser for
those.

## Install

macOS and Linux, no sudo:

```sh
curl -fsSL https://raw.githubusercontent.com/flexdinesh/servef/main/scripts/install-native.sh | sh
```

Latest `main` (the `edge` prerelease; no macOS Intel builds):

```sh
curl -fsSL https://raw.githubusercontent.com/flexdinesh/servef/main/scripts/install-native-edge.sh | sh
```

The app carries its own `servef` binary for the daemon, so it needs no other
install. The scripts link `servef-native` into `~/.local/bin` (or `~/bin`).

- macOS: `servef-native.app` goes to `/Applications` (or `~/Applications`).
  Builds are ad-hoc signed, not notarized.
- Linux: the app goes to `~/.local/share/servef-native/`, with a desktop
  entry that opens `servef-native://` links and an icon.

Run a script again to update; quit the app first. Remove it with
`scripts/uninstall.sh`, which keeps its settings.

## Use

```sh
servef-native .
```

opens the current directory. Only one copy runs: a second `servef-native`
command or link opens in the running app. The `servef` command never opens
the native app.

Links use the `servef-native://` scheme:

- `servef-native://local/?project=/path/to/repo&path=README.md` opens a file
  through the daemon on this computer.
- `servef-native://<host>:<port>/?project=/path/to/repo` opens a servef
  server. The app asks once before it connects to a server that is not on
  this computer.

The start page lists servef servers running on this computer and connects to
any server by address.
