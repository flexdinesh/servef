# Browsing

## Views

How a file is shown depends on its type, not on the [scope](/usage#filename-scope):

- Markdown opens in Source. Choosing Preview opens other documents in the
  project in Preview until you choose Source, for the rest of the browser tab.
  Images open in Preview; SVG also has Source.
- JSON/YAML open in Source; Format shows a formatted, highlighted view on
  demand. Invalid files stay readable and searchable in Source.
  YAML formatting retains comments, anchors/aliases, scalar styles, and all
  documents; spacing and comment placement can change in the formatted view.
- HTML, CSS, and JavaScript also open in Source with Format on demand. Format
  only reindents and breaks lines: comments, strings, and values are kept
  verbatim, as are `pre`, `textarea`, `script`, `style`, and inline SVG
  content. HTML tag and attribute names show lowercase. JavaScript containing
  JSX or that fails to tokenize keeps Source with a format notice.
- Known languages and config files show highlighted source, highlighted in
  the browser with WebAssembly. Unknown text files, and Fish, INI,
  Properties, and reStructuredText files, show plain text.
- Mermaid diagrams render as themed SVG with ondine, in Markdown fences and
  `.mmd`/`.mermaid` files (open in Preview); expand to zoom and pan.

Formatting is read-only; original files stay unchanged.

Markdown Preview hides leading frontmatter enclosed by matching `---` (YAML) or
`+++` (TOML) lines, and HTML comments. Source preserves both. Unclosed frontmatter
stays visible; comment syntax inside code stays literal.

## Binary and large files

- Binary files (a NUL byte in the first 8000 bytes) other than images show a
  "Binary file" note and are excluded from content search.
- Files over 4 MiB show plain, unhighlighted source without preview or
  formatting; image previews stay available. Files over 8 MiB are also
  excluded from content search.
- Non-image files over 32 MiB are not read; they show a "Too large to display"
  note.

## Explorer and tabs

- Switch between Explorer, Search, and Source Control from a VS Code-style
  activity bar (Cmd/Ctrl+Shift+E, Cmd/Ctrl+Shift+F, Cmd/Ctrl+Shift+G); click
  the active item or press Cmd/Ctrl+B to hide the sidebar.
- Navigate files in a compact, resizable tree.
- Filter file names and paths with Pierre Trees (Cmd/Ctrl+P; Cmd/Ctrl+K alias).
- Keep visited documents in an editor-style tab bar; right-click a tab to close
  it, other tabs, tabs to its right, or all tabs.

## Line links and paths

- Select lines or ranges from the line numbers (drag or Shift-click) to copy
  `path:12-20`; share `#L12-L20` links that open with the range highlighted.
- Diffs select lines the same way and copy the side's own lines: `path:12-20`
  for the new side, HEAD's (or the parent commit's) numbers for deleted lines.
  Links name the file and side: `#f=src/App.tsx&R12-R20` for the new side,
  `&L5` for the old; they open scrolled to the lines, expanding unchanged
  lines they name.
- Step through a review's changes with F7 and Shift+F7 or the toolbar's
  Previous change and Next change; steps cross into the next or previous
  file and select the change, so its link and `path:12-20` copy are one
  click away.
- Copy the open file's or reviewed file's path from the status bar.

## Search

Search file content in the Search view (Cmd/Ctrl+Shift+F or Find in files in
the status bar) like VS Code: every match grouped by file, Match Case, Match
Whole Word, and regular expressions, files to include/exclude globs, and
F4/Shift+F4 to step through matches. Files git ignores are skipped, including
global excludes and linked-worktree excludes.

## Source Control

Source Control lists what you can review: Uncommitted (every modified, added,
untracked, deleted, or renamed file since the last commit), Branch (every file
your branch changed since it left its base, as a pull request shows), then
your branch's commits. The base defaults to `origin/HEAD`, `main`, or
`master`; pick another branch from the Branch row, and servef remembers it
per project. Switch to All for the whole history, 50 commits at a time.
servef reads git data directly; `git` need not be installed.

Click a row to see its files below the list, with line counts, status
letters, and Expand/Collapse All Folders; a commit also shows its message,
author, date, and hash (Cmd/Ctrl+C copies it). Shift-click or Shift+Arrow
across commits to see only their combined changes; Escape or Clear range
narrows back to one commit. Drag between the list and the files to resize.

Open a file, or press Enter on a row, to review the whole selection in one
tab: every file's diff stacked under a sticky header, loaded as you scroll,
with split or unified view, wrap, ignore whitespace, word or character inline
changes, expand unchanged, and Expand/Collapse All Files. Mark files Viewed to
fold them away; a mark clears when the file changes again. Uncommitted and
Branch reviews follow new edits and commits; commit and range reviews stay
fixed. On phones, tap a row to see its files and Back to return; long-press a
commit, then tap another, to select a range.

## Settings and commands

- Choose a theme (system, light, dark, editor palettes) and interface font size
  in Settings (gear in the status bar, Cmd/Ctrl+,); search, browse categories,
  or filter modified preferences. Changes apply immediately and save in the
  browser.
- Run commands from a VS Code-style command palette (Cmd/Ctrl+Shift+P or F1);
  each setting is a command that opens Settings at it.
- The status bar shows document details; disclose process CPU/RAM from Ready.
