# Getting started

## Install

### Install script

macOS and Linux, no sudo:

```sh
curl -fsSL https://raw.githubusercontent.com/flexdinesh/servef/main/scripts/install.sh | sh
```

It installs the latest release's `servef` in `~/.local/bin` (or `~/bin` when
that is on your `PATH`), and prints the line to add when the directory is not
on `PATH`. Run it again to update.

### Homebrew

```sh
brew install flexdinesh/tap/servef
```

### Go

Requires Go 1.26 or later.

Latest stable release:

```sh
go install github.com/flexdinesh/servef@latest
```

Specific stable version:

```sh
go install github.com/flexdinesh/servef@v0.1.3
```

Latest `main` with embedded frontend assets:

```sh
go install github.com/flexdinesh/servef@edge
```

These installs include the embedded frontend; Node.js and pnpm are not required.
Other branches and commits do not include it and fail to build with
`go install`.

### Desktop app

Optional. The desktop app and the CLI, macOS and Linux:

```sh
curl -fsSL https://raw.githubusercontent.com/flexdinesh/servef/main/scripts/install-desktop.sh | sh
```

Packages are also on
[GitHub Releases](https://github.com/flexdinesh/servef/releases); see
[Desktop app](/desktop).

### Uninstall

```sh
curl -fsSL https://raw.githubusercontent.com/flexdinesh/servef/main/scripts/uninstall.sh | sh
```

It removes the CLI and the desktop app however they were installed in your
home directory, prints the command for Homebrew or the deb, and keeps your
data.

## Run

Serve the current directory:

```sh
servef .
```

With the [desktop app](/desktop) installed, servef opens the directory in it.
Otherwise it opens the browser UI on the first free port from `7971` through
`7980`; `servef browser .` always does. See [Usage](/usage) for directories,
scope, and ports, and
[Browsing](/browsing) for the UI.

See all options:

```sh
servef --help
```
